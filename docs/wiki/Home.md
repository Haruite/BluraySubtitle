New users can follow the interface guide and consult the concept pages as needed. Developers should read the code standards, then the developer guide and the relevant pipeline section.

The wiki covers media identification, extraction, remuxing, and encoding. It does not implement full HDMV/BD-J navigation, disc decryption, or disc authoring. Binary descriptions are based on the project parsers and the sources collected in References.
